# 扇子HP エックスサーバー移行と自動公開の設定手順

- 対象：扇子訪問看護ステーション（株式会社大福）HP → https://daifuku-sense.com/
- 作成日：2026年10月23日（And One／丸山）
- 決定：2026-10-23 丸山さん「A案：エックスサーバーへ移す・noindexも入れる」
- 関連：maruyama-omaru/maruyama-works の `docs/20261007_AndOneHP自動公開の設定手順_v1.md`（同じ仕組み）

> **FTP のパスワードは、この手順書・AI・メール本文・チャットに書かないでください。** 登録先は 3章の GitHub の「Secrets」だけです。

## 0. いまの状態（2026-10-23）

| 項目 | 状態 |
| --- | --- |
| サイトの中身 | このリポジトリ（HTML・CSS・JavaScript のみ。PHP なし） |
| 確認用の公開先 | GitHub Pages：https://maruyama-omaru.github.io/sense-hp/ （合言葉ゲートつき） |
| ドメイン daifuku-sense.com | 丸山さんの XServer アカウント（chru724660）で 2026-05-22 取得。レンタルサーバーには**まだ追加していない** |
| 検索エンジン | 全ページに `noindex`（公開前の確認用のため） |
| お問い合わせフォーム | **ダミー**（送信しても届かない。`js/main.js`） |

## 1. daifuku-sense.com をレンタルサーバーに追加する（丸山さん・初回のみ）

1. エックスサーバーのサーバーパネル →「ドメイン設定」→「ドメイン設定追加」
2. ドメイン名 `daifuku-sense.com` を入れ、「無料独自SSLを利用する」に**チェック**して追加
3. 「PHP Ver.切替」で daifuku-sense.com を **PHP8.3.36（推奨）** にする（サイトは PHP を使わないが、ほかのドメインとそろえる）
4. SSL が有効になるまで最大1時間ほどかかります（その間 https で開けないのは正常）

ドメインもサーバーも同じ XServer アカウントなので、ネームサーバーの設定は通常いりません（初期設定のままなら自動でつながります）。

## 2. 自動公開専用の FTP アカウントを作る（丸山さん・初回のみ）

1. サーバーパネル →「FTPアカウント設定」→ ドメイン `daifuku-sense.com` を選ぶ →「FTPアカウント追加」

| 項目 | 設定 |
| --- | --- |
| FTPアカウント名 | 例：`deploy@daifuku-sense.com` |
| 接続先ディレクトリ | `daifuku-sense.com/public_html/`（**このサイトのフォルダだけ**） |
| パスワード | 長く推測されにくいもの（iPhone の「強力なパスワード」など） |

2. 「FTPソフト設定」で FTP ホスト名（`sv〇〇〇〇.xserver.jp`）を控える

## 3. GitHub に登録する（丸山さん・初回のみ）

1. https://github.com/maruyama-omaru/sense-hp/settings/secrets/actions を開く
2. 「Secrets」タブ →「New repository secret」で3つ

| Name | 中身 |
| --- | --- |
| `SENSE_FTP_SERVER` | FTP ホスト名 |
| `SENSE_FTP_USERNAME` | 2章の FTP アカウント名 |
| `SENSE_FTP_PASSWORD` | 2章のパスワード |

3. 「Variables」タブ →「New repository variable」：`SENSE_DEPLOY_ENABLED` = `dryrun`

## 4. 動作確認

1. GitHub の「Actions」→「扇子HP 自動公開（エックスサーバー）」→「Run workflow」
2. ログの「エックスサーバーへアップロード」で、**削除（delete）が0件**・上げる先がサイトのファイル（index.html・css/・img/ など）であることを確認（Claude Code にログを見せてもよい。パスワードは出ない）
3. `SENSE_DEPLOY_ENABLED` を `true` にして、もう一度「Run workflow」→ https://daifuku-sense.com/ で合言葉ゲートが出れば成功

## 5. 移行が終わったら

- GitHub Pages を止める：Settings → Pages →「Unpublish site」
- リポジトリを非公開にする：Settings → General → 一番下「Change repository visibility」→ Private
  （非公開でも GitHub Actions の自動公開は動く。無料枠は月2,000分で、1回1〜2分）

## 6. 本番公開（先方の OK が出たら）

- 全ページの `<meta name="robots" content="noindex, nofollow" />` の行を消す
- `js/gate.js` の読み込み（各ページの `<script src="js/gate.js"></script>`）を消す
- お問い合わせフォームを本物にする（PHP の送信処理を作る／電話・メールのボタンに置き換える、のどちらか）
- Google Search Console に daifuku-sense.com を登録
